NAP -> Maps (Térképek). Green country labels mean a verified, installed road database whose size and file timestamp still match the worker record. Yellow means selected and queued/downloading/building/verifying. The rows update without reopening or resetting scroll. Country selection is enabled only offroad or with fresh stationary vehicle data. The worker downloads/builds only offroad on Wi-Fi and pauses on loss of those conditions. Deselecting removes only that country map. Already-installed HU/SI/IT maps are adopted without re-downloading. Map installation does not change cruise targets, steering, radar or pedal handling.
Tests: python tools/road_context/test_maps.py and python tools/road_context/test_association.py. ARM64 test construction uses mocked font metrics without opening a second display. Native pyosmium import and isolated worker startup are checked separately.
